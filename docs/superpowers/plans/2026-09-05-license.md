# License Implementation Plan

> **For agentic workers:** Execute inline in this session. User already approved the spec and said 开始执行.

**Goal:** Desktop app requires a machine-bound, 3-month Ed25519 license before use; a password-gated issuer in the same app generates licenses.

**Architecture:** Rust owns machine id, sign, verify, and `license.lic` in app data dir. Frontend shows a full-screen gate when invalid (Tauri only). Issuer password encrypts the private key at build time and is never stored in source.

**Tech Stack:** Tauri 2, ed25519-dalek, ChaCha20-Poly1305, PBKDF2-SHA256, React.

## Global Constraints

- Validity: issuedAt local calendar date + 3 months.
- Machine id: Windows MachineGuid; issuer types target id manually.
- Vite/jsdom: skip gate (`isTauriRuntime()` false).
- Password not committed in plaintext.
